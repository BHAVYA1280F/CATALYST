# Catalyst

### Logic First. Syntax Later.

Catalyst is a beginner-friendly coding learning platform designed to bridge the gap between visual programming and traditional text-based programming languages.

Many beginners struggle when moving from block-based environments such as Scratch to languages like Java, Python, or C++. The problem is often not the programming concept itself, but the sudden introduction of complex syntax.

Catalyst addresses this gap by allowing learners to express programming instructions using simple English, understand the underlying logic, visualize execution, and then see how the same logic translates into real programming languages.

---

## Why Catalyst?

Learning programming traditionally introduces beginners to two things at the same time:

- Programming logic
- Programming syntax

For a beginner, this can create unnecessary cognitive load.

For example, a student may understand:

> "Create a score with 0. Repeat 5 times and add 2 to the score."

But writing the equivalent code requires knowledge of variables, loops, syntax, indentation, operators, and language-specific rules.

Catalyst separates these concepts.

### The learning approach:

**Simple English → Logical Steps → Execution → Programming Syntax**

This allows learners to focus on understanding what a program does before worrying about how a particular programming language writes it.
